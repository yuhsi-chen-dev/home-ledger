## 怎麼加一條

1. 取下一個編號，檔名 `<編號>-<英文-slug>.md`。
2. 表頭放**狀態**與**日期**，內文照這個順序寫：
   **問題**（為什麼需要決定）→ **決定** → **理由 / 為什麼不是另一種做法**
   → **已知天花板**（這個決定什麼時候會不夠用、到時候換成什麼）。
3. 如果它推翻了舊的某一條：改舊那條的**狀態**欄指向新的，
   **不要動舊的內文**。
4. 回到這張表加一列。

「已知天花板」不是免責聲明，是給未來的自己看的觸發條件——
寫清楚「撞到什麼就該回來改」，比寫「未來可能需要優化」有用。
